Breadboard Bench

ELT 1206 study bench: build a circuit, read the meters, check the math.

Import from LTspice

Open a schematic (.asc) or netlist (.net, .cir), or paste the netlist from LTspice (View → SPICE Netlist). Ground and supplies go on the rails, every other node gets its own column, and op-amps become LM1458 chips. This replaces the board.

Series and parallel

Series: RT = R1 + R2 + … · Parallel: 1/RT = 1/R1 + 1/R2 + …

Voltage divider and loading

Vout = VS · R2 / (R1 + R2)

RC and RL time constant

τ = RC or L/R · v(t) = Vs(1 − e^(−t/τ))

Sine wave

Vpp = 2Vp · Vrms = 0.707·Vp · f = 1/T · ω = 2πf

Phasor converter

a = M·cos θ · b = M·sin θ · M = √(a² + b²) · θ = tan⁻¹(b/a)

Reactance and impedance

XL = 2πfL · XC = 1/(2πfC) · Z = R + jX
